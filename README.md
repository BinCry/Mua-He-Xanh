## 🌟 Giới thiệu Dự án

**Bình Lợi Healing** là hệ thống nền tảng công nghệ số phục vụ phát triển **Du lịch Sinh thái – Nông nghiệp – Văn hóa Chữa lành** tại xã Bình Lợi, huyện Bình Chánh, TP. Hồ Chí Minh. Nền tảng kết nối du khách với các vườn mai vàng, không gian trải nghiệm sinh thái, nghệ nhân địa phương và các sản phẩm đặc trưng OCOP thông qua trải nghiệm web hiện đại, mượt mà và cá nhân hóa.

1. **🗺️ Bản đồ Du lịch Số Tương tác (Interactive Smart Map):**
   * Hiển thị trực quan toàn bộ điểm đến (Vườn mai vàng, Nông trại sinh thái, Di tích lịch sử, Ẩm thực làng quê).
   * Lọc thông minh theo danh mục, tích hợp chỉ đường lái xe turn-by-turn bằng OSRM và nút kết nối trực tiếp Google Maps App.

2. **🧭 Xây dựng Hành trình Tự động & Cá nhân hóa (Story Journey Mode):**
   * Gợi ý lịch trình thông minh theo từng mùa trong năm (Xuân, Hạ, Thu, Đông) và vibe cảm xúc (Chill, Peace, Culture, Family).
   * Kéo - thả sắp xếp điểm đến (Drag & Drop), tự động tính toán lại thời lượng và số km tức thì.

3. **📷 Quét mã QR Check-in & Gamification:**
   * Quét mã QR tại từng điểm dừng chân để ghi nhận lượt ghé thăm và tích điểm thưởng du lịch.
   * Cửa hàng đổi quà trực tuyến (Voucher, nông sản, quà lưu niệm) với mã nhận diện duy nhất.

4. **🛍️ Đặt chỗ Workshop Sinh thái & Chợ Nông sản OCOP:**
   * Khám phá và đăng ký tham gia các khóa trải nghiệm (làm bánh, trồng mai, thủ công mỹ nghệ).
   * Quản lý trạng thái đặt chỗ, thông báo nhắc hẹn.

5. **💬 Hộp thư & Trò chuyện Trực tuyến Thời gian thực (Live Support):**
   * Giao diện nhắn tin trực tiếp phong cách Messenger giữa du khách và Ban Quản trị / Quản lý điểm đến.
   * Tự động lọc cập nhật mới, giao diện mượt mà không load lại trang.

6. **📊 Hệ thống Quản trị Đa cấp bậc (Super Admin & Destination Manager):**
   * **Super Admin**: Quản lý người dùng, duyệt điểm đến, sự kiện, hành trình mẫu, thống kê biểu đồ doanh thu và check-in.
   * **Destination Manager**: Quản lý thông tin điểm đến riêng, quản lý hội thảo, theo dõi đơn đặt chỗ và tương tác khách hàng.

## 🛠️ Hướng dẫn Cài đặt & Chạy Cục bộ (Local Development)

### 1. Yêu cầu hệ thống
* **Node.js**: Phiên bản `>= 20.x`
* **PostgreSQL**: Phiên bản `>= 15.x`
* **Git**

### 2. Clone mã nguồn
```bash
git clone https://github.com/td22042006/binh-loi-healing.git
cd binh-loi-healing
```

### 3. Cài đặt các gói phụ thuộc
```bash
npm install
```

### 4. Cấu hình biến môi trường
Tạo file `.env` tại thư mục gốc dự án theo mẫu:
```env
PORT=3000
NODE_ENV=development
BASE_URL=http://localhost:3000

# Cấu hình Cơ sở dữ liệu PostgreSQL
DB_HOST=localhost
DB_PORT=5432
DB_NAME=binh_loi_db
DB_USER=postgres
DB_PASSWORD=your_password

# Session Secret
SESSION_SECRET=your_super_secret_session_key

# Google OAuth (Tùy chọn)
GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret
GOOGLE_CALLBACK_URL=http://localhost:3000/auth/google/callback

# Cloudinary (Tùy chọn tải ảnh)
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret
```

### 5. Khởi chạy ứng dụng
* **Chế độ phát triển (Tự reload khi sửa code):**
  ```bash
  npm run dev
  ```
* **Chế độ chính thức:**
  ```bash
  npm start
  ```
* Mở trình duyệt và truy cập: `http://localhost:3000`
